## set-up react

- npm init -y

        npm react
        npm react-dom
        npm react-scripts

- package.json

            "script":"ract-scripts start"

- public
  - index.html
- src
  - app.js
  - index.js

### command to get the react setup/environment

1. CRA
   - `npx create-react-app project_name`

2. VITE
   - `npm create vite@latest project_name`
   - `npm create vite@latest ./`
